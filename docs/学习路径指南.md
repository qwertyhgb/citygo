# CityGo 项目学习路径指南

> 本指南按照从基础到进阶的顺序，帮助你系统地学习 CityGo 项目的各个模块。

## 📚 学习路径总览

```
阶段 1: 工程基础 (必学)
    ↓
阶段 2: 认证与权限 (核心)
    ↓
阶段 3: 基础 CRUD (入门业务)
    ↓
阶段 4: 核心业务链路 (重点)
    ↓
阶段 5: 进阶技术 (提升)
    ↓
阶段 6: 高级场景 (实战)
```

## 🎯 阶段 1: 工程基础 (1-2天)

**目标**: 理解项目的架构设计和工程实践

### 学习顺序

1. **项目骨架** (最优先)
   - 📄 `docs/notes/01-项目骨架与工程实践.md`
   - 📄 `README.md`
   - 📄 `pom.xml`
   
   **重点掌握**:
   - Spring Boot 4.1 的新特性 (starter 命名变化)
   - 统一返回结构 `Result<T>`
   - 全局异常处理 `GlobalExceptionHandler`
   - 错误码设计 `ErrorCode`
   - 日志配置 `logback-spring.xml`
   - 多环境配置 (dev/test/prod)

   **实战练习**:
   ```bash
   # 启动项目
   mvn spring-boot:run
   
   # 访问 Swagger 文档
   http://localhost:8080/swagger-ui.html
   
   # 测试 ping 接口
   curl http://localhost:8080/api/ping
   ```

2. **数据库设计** (第二优先)
   - 📄 `docs/notes/02-数据库设计与迁移.md`
   - 📄 `docs/database-design.md`
   - 📂 `src/main/resources/db/migration/`
   
   **重点掌握**:
   - 14 张表的设计逻辑和关系
   - 为什么不用物理外键
   - 雪花 ID 的使用
   - 软删除机制
   - 订单快照设计
   - Flyway 迁移管理

   **实战练习**:
   ```sql
   -- 查看数据库表结构
   SHOW TABLES;
   DESC user;
   DESC orders;
   
   -- 查看 Flyway 迁移记录
   SELECT * FROM flyway_schema_history;
   ```

**阶段产出**: 
- ✅ 理解项目整体架构
- ✅ 掌握统一异常处理和返回结构
- ✅ 熟悉数据库设计思路

## 🔐 阶段 2: 认证与权限 (2-3天)

**目标**: 理解 JWT + Spring Security 的认证授权体系

### 学习顺序

1. **认证基础**
   - 📄 `docs/notes/03-认证与权限.md`
   - 📂 `src/main/java/com/citygo/auth/`
   
   **重点掌握**:
   - JWT 生成与解析 (`JwtUtil`)
   - Spring Security 配置 (`SecurityConfig`)
   - 过滤器链 (`JwtAuthenticationFilter`)
   - 密码加密 (BCrypt)
   - 角色与权限设计

   **核心文件**:
   ```
   auth/security/JwtUtil.java           - JWT 工具类
   auth/security/SecurityConfig.java    - Security 配置
   auth/security/JwtAuthenticationFilter.java - JWT 过滤器
   auth/controller/AuthController.java  - 注册/登录接口
   auth/service/impl/AuthServiceImpl.java - 认证逻辑
   ```

2. **用户与角色**
   - 📄 `docs/notes/04-用户与角色模型.md`
   - 📂 `src/main/java/com/citygo/user/`
   
   **重点掌握**:
   - 用户-角色多对多关系
   - 三种角色: USER / MERCHANT / ADMIN
   - `@PreAuthorize` 权限注解

   **实战练习**:
   ```bash
   # 1. 注册用户
   curl -X POST http://localhost:8080/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{"username":"test001","password":"123456"}'
   
   # 2. 登录获取 token
   curl -X POST http://localhost:8080/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"username":"test001","password":"123456"}'
   
   # 3. 使用 token 访问需要认证的接口
   curl http://localhost:8080/api/users/me \
     -H "Authorization: Bearer YOUR_TOKEN"
   ```

**阶段产出**:
- ✅ 掌握 JWT 认证流程
- ✅ 理解 Spring Security 配置
- ✅ 会使用角色权限控制

## 📦 阶段 3: 基础 CRUD (2-3天)

**目标**: 学习标准的 CRUD 业务模块，掌握 MyBatis-Plus

### 学习顺序 (按难度递增)

1. **收货地址** (最简单，纯 CRUD)
   - 📂 `src/main/java/com/citygo/address/`
   - 功能: 增删改查、设置默认地址
   - 技术点: MyBatis-Plus BaseMapper、逻辑删除

2. **商品分类** (树形结构)
   - 📄 `docs/notes/06-商品与分类.md`
   - 📂 `src/main/java/com/citygo/category/`
   - 功能: 父子分类、按层级查询
   - 技术点: 自关联表、递归查询

3. **商家与店铺** (关联关系)
   - 📄 `docs/notes/05-商家与店铺管理.md`
   - 📂 `src/main/java/com/citygo/merchant/`
   - 📂 `src/main/java/com/citygo/shop/`
   - 功能: 商家注册、店铺管理、归属校验
   - 技术点: 一对多关系、权限校验

4. **商品管理** (业务校验)
   - 📄 `docs/notes/06-商品与分类.md`
   - 📂 `src/main/java/com/citygo/product/`
   - 功能: 商品 CRUD、上下架、库存管理
   - 技术点: 状态管理、库存扣减

**实战练习**:
```bash
# 完整业务流程演练
# 1. 注册成为商家
# 2. 创建店铺
# 3. 添加商品
# 4. 上架商品
# 5. 用户端浏览商品
```

**阶段产出**:
- ✅ 掌握 MyBatis-Plus 基本用法
- ✅ 理解实体-DTO-VO 的转换
- ✅ 学会权限归属校验

## 🛒 阶段 4: 核心业务链路 (3-5天)

**目标**: 掌握电商核心流程和事务处理

### 学习顺序

1. **购物车** (Redis 实战)
   - 📄 `docs/notes/07-购物车.md`
   - 📂 `src/main/java/com/citygo/cart/`
   - 功能: 添加、修改、删除、清空购物车
   - 技术点: **Redis Hash**、购物车合并

   **重点掌握**:
   - Redis 数据结构选择
   - 购物车与订单的衔接
   - 登录态与购物车绑定

2. **订单核心链路** (重中之重 ⭐⭐⭐)
   - 📄 `docs/notes/08-订单核心链路.md`
   - 📂 `src/main/java/com/citygo/order/`
   - 功能: 下单、支付、取消、状态流转
   - 技术点: **事务管理**、库存扣减、订单快照、状态机

   **核心流程**:
   ```
   下单 → 扣库存 → 创建订单 → 清购物车
     ↓
   支付 → 更新订单状态 → 累加销量
     ↓
   商家接单 → 配送 → 完成
   ```

   **重点掌握**:
   - `@Transactional` 事务传播
   - 订单状态机设计 (10→20→30→40→50)
   - 订单明细快照
   - 乐观锁扣库存
   - 订单超时处理

3. **支付模块** (简化模拟)
   - 📂 `src/main/java/com/citygo/order/service/impl/PaymentServiceImpl.java`
   - 功能: 模拟支付、支付回调
   - 技术点: 支付流水、幂等性

**实战练习**:
```bash
# 完整下单流程
# 1. 添加商品到购物车
# 2. 查看购物车
# 3. 创建订单
# 4. 模拟支付
# 5. 查询订单状态
# 6. 商家接单
```

**阶段产出**:
- ✅ 掌握 Redis 在业务中的应用
- ✅ 理解订单状态机和事务管理
- ✅ 学会库存扣减和快照设计

## 🚀 阶段 5: 进阶技术 (3-4天)

**目标**: 学习 Redis、RabbitMQ、Elasticsearch 的实战应用

### 学习顺序

1. **Redis 进阶** (缓存、锁、限流)
   - 📄 `docs/notes/09-Redis 进阶.md`
   - 📂 `src/main/java/com/citygo/common/cache/`
   - 📂 `src/main/java/com/citygo/common/lock/`
   
   **重点掌握**:
   - 分布式锁 (`@RedisLock` 切面)
   - 防重复提交 (`@PreventRepeatSubmit`)
   - 限流 (`@RateLimit`)
   - 缓存穿透/击穿/雪崩

2. **RabbitMQ 消息队列**
   - 📄 `docs/notes/10-RabbitMQ.md`
   - 📂 `src/main/java/com/citygo/order/mq/`
   
   **重点掌握**:
   - 订单超时处理 (TTL + 死信队列)
   - 消息可靠性保证
   - 消费者重试机制
   - `@RabbitListener` 消费者

3. **Elasticsearch 搜索**
   - 📄 `docs/notes/14-Elasticsearch.md`
   - 📂 `src/main/java/com/citygo/search/`
   
   **重点掌握**:
   - 店铺/商品索引设计
   - IK 分词器使用
   - 全文搜索与高亮
   - MySQL 与 ES 数据同步

**实战练习**:
```bash

# 用 JMeter 并发测试分布式锁

# RabbitMQ 测试

# ES 搜索测试
curl "http://localhost:8080/api/search/shops?keyword=火锅&city=成都"
```

**阶段产出**:
- ✅ 掌握 Redis 高级用法
- ✅ 理解消息队列的异步处理
- ✅ 学会 Elasticsearch 全文搜索

- 每个模块学完后，用 Postman/curl 测试所有接口

### 2. 调试技巧
```java
// 在关键位置打断点
@Transactional
public void createOrder(...) {
    // 断点 1: 查看入参
    log.debug("创建订单，参数: {}", request);
    
    // 断点 2: 查看扣库存后的数据
    productMapper.deductStock(...);
    
    // 断点 3: 查看订单创建结果
    ordersMapper.insert(order);
}
```

### 3. 查看日志
```bash
# 实时查看日志
tail -f logs/citygo-server.log

# 过滤订单相关日志
tail -f logs/citygo-server.log | grep "order"

# 查看 SQL 执行
# application-dev.yml 中已开启: log-impl: Slf4jImpl
```

### 4. 代码导航
- 从 Controller 开始，往下追 Service → Mapper
- 看单元测试了解用法
- 看 DTO/VO 了解数据流转
- 看 Mapper XML 了解 SQL 逻辑

### 5. 文档优先
- 每个阶段先读对应的 `docs/notes/*.md`
- 再看代码实现

## 🔍 常见问题

### Q1: 我是初学者，应该跳过哪些部分？
**A**: 
- 必学: 阶段 1、2、3、4 的订单部分
- 可选: 阶段 5 的 RabbitMQ、ES
- 进阶: 阶段 6 的秒杀

### Q2: 如何快速上手？
**A**: 
1. 先跑通项目 (mvn spring-boot:run)
2. 看 Swagger 文档理解接口
3. 按阶段 1 → 2 → 3 顺序学习
4. 每个模块都要自己测试接口

### Q3: 学习周期要多久？
**A**: 
- 快速浏览: 3-5 天
- 深入学习: 2-3 周
- 精通掌握: 1-2 月 (含扩展实战)

### Q4: 如何判断是否掌握？
**A**: 
- 能独立实现一个类似模块
- 能解释设计决策 (为什么这么做)
- 能应对面试相关问题
- 能优化或扩展现有功能
